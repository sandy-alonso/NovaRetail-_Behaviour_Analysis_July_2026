# ¿A qué clientes debía venderle NovaRetail y no lo sabía?

## Desafío
NovaRetail no sabía qué factor determinaba realmente cuánto gastaban sus clientes, por lo que sus esfuerzos de venta no tenían un enfoque claro.

## Proceso
Analicé los datos de clientes en Python (Jupyter), calculando correlaciones con los métodos de Pearson y Spearman para identificar qué variables predecían mejor el gasto.
